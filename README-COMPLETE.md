# FitLife - Modern Gym & Fitness Center

Complete project package.

## Run

Recommended: open `Fitlife--main/index.html` with VS Code Live Server (or any local web server), because the site loads header/footer/sections from the `components/` folder with JavaScript fetch().

## Main features
- Responsive FitLife gym website
- Scrolling browser title: FitLife - Modern Gym & Fitness Center
- Header scrolling title
- Search bar
- Dark/light theme toggle
- Responsive mobile menu
- Protein product section with prices
- Product details accordion
- WhatsApp enquiry buttons
- Masonry-style product layout to avoid desktop blank space when details expand
