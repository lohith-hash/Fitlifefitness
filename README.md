FitLife — Modern Gym & Fitness Center

FitLife is a modern, responsive gym and fitness center website designed around training, fitness services, gym equipment, nutrition, classes, trainers, memberships, and member communication.

The website is presented as a single-page experience with smooth navigation between its major sections. It includes a fitness-focused hero section, gym information, services, gym tools, nutrition/protein products, classes, trainers, membership information, and contact/feedback functionality.

Features

- Modern gym and fitness center landing page
- Responsive single-page website layout
- Hero section with training-focused call-to-action buttons
- About section describing FitLife and its training environment
- Services section
- Gym tools and equipment section
- Equipment product cards with pricing and specifications
- WhatsApp enquiry buttons for equipment
- Nutrition/protein product section
- Protein product details and pricing
- WhatsApp enquiries for products
- Fitness classes section
- Trainers section
- Membership section
- Contact and feedback section
- Feedback form with service selection
- WhatsApp-based message submission
- Built-in website search
- Search results that navigate directly to matching sections
- Mobile navigation menu
- Light/dark theme toggle
- Theme preference stored using browser local storage
- Google Maps location embed
- Phone, email, and opening-hours contact information
- Smooth scrolling navigation

The website navigation provides direct access to Gym Tools, About, Services, Protein, Classes, Trainers, Membership, and Contact sections.

Gym & Fitness Content

The FitLife website presents itself as a modern fitness center for beginners through experienced athletes. The included content highlights professional trainers, modern equipment, personalized workout programs, nutrition guidance, and a clean training environment.

The Gym Tools section includes practical strength, functional, and grip-training equipment with reference pricing, specifications, and WhatsApp enquiry functionality.

Interactive Features

Website Search

The header contains a FitLife search feature. It searches the website's section IDs, headings, and section text and displays matching sections as navigation results.

Theme Switching

The website includes a light/dark theme switch. The selected theme can be stored in "localStorage", allowing the preference to persist in the browser.

Mobile Navigation

The navigation menu can be opened and closed through the menu button, with keyboard and outside-click handling included in the JavaScript functionality.

WhatsApp Feedback

The feedback form validates the submitted fields and constructs a WhatsApp message containing the submitted name, phone number, email, selected service, and message before opening WhatsApp.
